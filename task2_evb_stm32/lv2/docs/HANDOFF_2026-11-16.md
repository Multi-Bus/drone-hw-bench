## Initialization rule verified in driver source

`dwt_readdevid` and `dwt_checkidlerc` reach the register transfer code that
reads `LOCAL_DATA(dw)->spicrc` (`dw3000_device.c:509`). `dw->priv` is first set
by `ull_initialise` at line 1016. Do not use these register APIs before
successful initialization, and do not enable a driver ISR before that point.
Use adapter `uwb_port_read_status()` for pre-init readiness checks, with
error/timeout handling. `dwt_probe()` has its own direct-SPI ID path.
This verifies the source-level unsafe access, not a debugger-captured HardFault.
